# Crypto Casino Platform (Solana + EVM) — Proof of Concept

Este projeto é um **casino Web3 híbrido**, compatível com **Solana** e **EVM**, com três jogos implementados:

- Coinflip  
- Dice  
- Roulette  

Inclui:

- Bankroll Manager com limites dinâmicos  
- Emergency Shutdown System  
- Suporte para testnet e preparação para mainnet  
- RNG híbrido: Switchboard (Solana) + Chainlink VRF (EVM) + fallback Commit-Reveal  
- Infraestrutura simplificada com Docker

---

## 🔧 Tecnologias

### Frontend
- Next.js + React  
- Zustand para state management  
- Conectores: Phantom, Solflare, MetaMask, Coinbase Wallet

### Backend
- Node.js + TypeScript  
- Express  
- Solana Web3 SDK  
- ethers.js  
- Switchboard RNG  
- Chainlink VRF  
- Bankroll + Risk Engine internos

### Smart Contracts
- Solana (Anchor)  
- EVM (Solidity + Hardhat)

### Infra
- Docker + docker-compose

## 🚀 Como correr o PoC

### 1. Criar `.env`
Copia o ficheiro `.env.example` para `.env`:

```bash
cp .env.example .env
````

Preenche com as tuas chaves e endpoints das testnets.

---

### 2. Usar Docker

Para levantar tudo:

```bash
docker-compose up --build
```

Serviços expostos:

* Frontend → [http://localhost:3000](http://localhost:3000)
* Backend → [http://localhost:8080](http://localhost:8080)
* Solana local validator (opcional) → 8899

# 📌 **docker-compose.yml**

```yaml
version: "3.9"

services:

  backend:
    build:
      context: ./backend
      dockerfile: ../docker/backend.Dockerfile
    container_name: casino-backend
    restart: unless-stopped
    ports:
      - "8080:8080"
    env_file:
      - .env
    depends_on:
      - solana-validator
    networks:
      - casino-net

  frontend:
    build:
      context: ./frontend
      dockerfile: ../docker/frontend.Dockerfile
    container_name: casino-frontend
    restart: unless-stopped
    ports:
      - "3000:3000"
    env_file:
      - .env
    networks:
      - casino-net

  solana-validator:
    image: solanalabs/solana:latest
    container_name: solana-local-validator
    command: |
      solana-test-validator
      --reset
      --limit-ledger-size
      --rpc-port 8899
    ports:
      - "8899:8899"
    networks:
      - casino-net

networks:
  casino-net:
    driver: bridge
```
